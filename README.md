# 二进制格式推断台

面向逆向分析的浏览器工具：上传多份二进制样本，对字节区间提出整数、字符串、枚举、偏移、长度、偏移表或校验字段假设，系统在全部样本上验证，记录每次验证的命中与反例，并将经过重叠裁决的字段发布成带版本的格式草案。

## 运行

```sh
corepack enable
pnpm install --frozen-lockfile
pnpm test -- --run
pnpm dev -- --host 127.0.0.1 --port 5225
# 打开 http://127.0.0.1:5225
```

运行期不访问外网；持久化数据写入 `data/state.json`（原子替换），重启后样本、假设、验证历史、候选与草案版本均保留。可用 `BFIB_DATA_FILE` 覆盖数据文件路径。

## 工作流

1. 在左上方面板选择一个或多个文件并填写来源备注，上传后系统自动在全部样本上重验既有假设。
2. 在十六进制视图拖选字节（半开区间），在下方表单声明字段类型与参数（端序、基准点、单位、锚点字段、校验算法与覆盖区等）。
3. 右侧查看假设状态、逐次验证历史与跨样本值表；反例单元格可点击跳到对应字节，区间层级用黄色虚线标出重叠解释。
4. 在“候选关系”页让系统扫描长度/偏移/校验相关性；候选会标明支持与反对样本数，只有人工“确认为假设”后才参与草案。
5. 在“格式草案”页勾选字段；重叠解释必须逐项显式裁决才能发布，版本号单调递增。可下载稳定 JSON 与独立解析生成器（`parser-vN.mjs`），或直接用当前样本在页面内试解析。

## 设计要点

- 所有整数内部以 `bigint` 解码（含 8/16/24/32/64 位、有符号/无符号）；偏移与长度计算先乘单位，再检查负数、安全整数上限与文档越界。
- 区间一律半开 `[start, end)`；`fixed` 区间的 `end: -1` 表示“到文档末尾”。
- 验证结果只追加不改写：新样本加入后产生一次新的验证记录，旧记录与“提出时样本集合”快照保持不变。
- 相同内容按 SHA-256 复用 blob，来源备注保存在各自的样本记录上。
- 生成器只依赖草案 JSON，解析越界输入时返回 `{ ok:false, errors:[{path,offset,message}] }`，不抛异常。

## 目录

- `src/shared/` 领域模型、字节/校验和工具、逐样本语义验证、候选发现、状态引擎、解析生成器
- `src/server/` 持久化仓库与 Vite 中间件 API
- `src/client/` React 页面：十六进制、区间层级、跨样本值表、假设/候选/草案面板
- `test/` Vitest 覆盖端序、相对偏移、整数溢出、重叠裁决、追加样本、内容去重、候选确认、生成器错误位置与稳定导出
