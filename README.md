# 二进制格式推断台（Binary Format Inference Bench）

给逆向工程团队使用的浏览器工具：上传多份二进制样本，对**半开字节区间** `[start, end)`
声明整数、字符串、枚举、偏移表、长度字段或校验字段假设，系统在**所有样本**上验证，
保留每一次验证证据，并把已确认的解释组合成**带版本的格式草案**。

## 快速开始

```bash
corepack enable
pnpm install --frozen-lockfile
pnpm test -- --run
pnpm dev -- --host 127.0.0.1 --port 5225
```

打开 http://127.0.0.1:5225 ，页面标题为「二进制格式推断台」。整个运行期不访问外网。

## 工作流

1. **上传样本**：可一次选择多份文件；内容相同的样本按 SHA-256 复用同一个 blob，
   每份样本的来源备注独立保留。
2. **框选区间**：在十六进制视图点击两个字节确定半开区间，点「声明假设」选择类型。
   - 整数/枚举/长度/校验：端序（LE/BE）、宽度（1/2/4/8）、有/无符号
   - 字符串：ASCII/UTF-8、是否要求 NUL 终止、是否仅可打印
   - 偏移表：项宽、项数、**基准点**（文件起点 / 表起点相对偏移 / 文件尾 / 另一区域）、**单位**（×1/×2/×4）
   - 长度：单位、目标（整文件 / 到 EOF 剩余 / 另一区域）
   - 校验：sum8 / sum16 / xor8，覆盖绝对区间或引用区域
3. **查看验证**：右侧跨样本值表给出每个假设在每份样本上的命中 / 反例 / 越界。
   点反例旁的 `→0x..` 按钮直接跳到该样本的对应字节。
4. **候选关系**：系统按值的相关性自动提出候选（字段等于某区域长度、到 EOF 的长度、
   简单校验值、常量），**必须标明支持样本数**，未确认绝不进入草案；点「确认并提升为假设」
   才会成为正式假设。
5. **重叠裁决**：重叠解释允许暂存；发布草案时，每一对未裁决重叠都会阻止发布，
   必须显式选择胜者并可填写理由。
6. **发布版本**：草案每次发布产生不可变版本，可下载
   - **稳定 JSON**：对象键排序，`canonicalHash` 为规范文本的 SHA-256，同内容导出字节一致
   - **解析器生成器**：一个只依赖草案、只负责解析的自包含 `.mjs`

## 生成器的错误语义

生成的解析器对任何输入都不抛异常，返回：

```ts
{ ok: true, value: Record<string, FieldValue>, bytesConsumed: number }
// 或
{ ok: false, path: "$.table[2]", offset: 14, code: "out_of_bounds", message: "…" }
```

`path` 是出错字段的 JSON 指针，`offset` 是输入中的绝对字节偏移；
`code` ∈ `out_of_bounds | overflow | invalid_enum | invalid_string`。
所有相对偏移计算都检查单位乘法与基准加法的整数溢出，并把解析出的目标钳制在缓冲区内报告。

## 证据与持久性

- 每条假设永久记录**提出时的样本集合**；追加样本从不改写旧结论，而是新增一次验证结果。
- 验证历史、候选、裁决、草案版本全部持久化在 `data/`（原子写入 `state.json` + blob 文件），
  重启后完整恢复。

## 目录

```
src/core/      领域模型、二进制原语、验证引擎、候选发现、草案/稳定导出、解析器引擎与生成器
src/server/    JSON/HTTP API、持久化
src/web/       React 界面：十六进制 / 区间层级 / 跨样本值表 / 候选 / 草案
test/          端序、相对偏移、整数溢出、重叠裁决、追加样本、去重、候选确认、
               生成器错误位置、半开边界、稳定导出、重启持久化
vite.config.ts 开发服务器把 API 中间件挂在同一端口（5225）
```
